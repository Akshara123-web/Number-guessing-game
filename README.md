# 🎯 Number Guessing Game (Python)

A simple Python-based number guessing game where the computer selects a random number within a user-defined range, and the player tries to guess it with helpful hints.

---

## 🚀 Features

* User-defined range (lower and upper limits)
* Random number generation
* Continuous guessing until correct
* Smart hints:

  * Too high 📉
  * Too low 📈
* Tracks number of attempts

---

## 🛠️ Tech Stack

* Python (built-in libraries like `random`)

---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repo.git
```

2. Navigate to the project folder:

```bash
cd your-repo
```

3. Run the program:

```bash
python scramble.py
```

---

## 🎮 How to Play

1. Enter a lower and upper limit
2. Try guessing the number chosen by the computer
3. Follow the hints to reach the correct answer
4. Game ends when you guess correctly 🎉

---

## 📌 Example

```
Enter lower limit: 1
Enter upper limit: 100
Guess the number: 50
Too low!
Guess the number: 75
Too high!
...
Correct! You guessed it in 5 attempts.
```
